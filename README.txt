LOCAL PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Internet is needed for Google Fonts; the rest of the site works locally.

PUBLISH USING GITHUB PAGES
1. Sign in to https://github.com
2. Create a PUBLIC repository named: sunayana-portfolio
3. Extract this ZIP on your computer.
4. In the new repository, choose Add file > Upload files.
5. Upload the CONTENTS of this folder (index.html, style.css, script.js, assets folder, and resume files). Do not upload only the ZIP.
6. Commit changes.
7. Go to Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose branch main and folder /(root), then Save.
10. Wait for GitHub Pages to finish publishing. Copy the exact URL shown in Settings > Pages.
